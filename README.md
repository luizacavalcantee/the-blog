## 🚀 Sobre o Projeto
Blog técnico desenvolvido em **48 horas** (02/09 a 04/10) como projeto de aprendizado.  
Focado em compartilhar conhecimentos sobre desenvolvimento web com artigos práticos e dicas.

## ⚡ Como Executar

```bash
# Clone o repositório
git clone https://github.com/luizacavalcantee/the-blog.git

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev
```

🔗 **Acesso Online**: [https://the-blog-dev.vercel.app/](https://the-blog-dev.vercel.app/)
